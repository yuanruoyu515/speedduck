# 隐私说明

更新日期：2026-10-22，适用于 speedduck 1.0.1。

speedduck 没有服务器、账号、广告、分析 SDK 或遥测。扩展运行时不向外部发送网络请求。

## 本机数据

| 数据 | 保存位置 | 用途 |
| :--- | :--- | :--- |
| 网站主机名与倍速 | `storage.local` | 可选的网站记忆，重启后保留。 |
| 锁速和音调开关 | `storage.local` | 全局偏好。 |
| 标签页 ID、URL、页面标记、倍速和播放器计数 | `storage.session` | 当前会话的导航处理、标签页记忆及状态显示；关闭标签页时移除对应记录。 |

扩展不会采集网页正文、表单内容、密码、支付信息或浏览历史列表。`tabs` 权限让扩展可以读取当前标签页 URL，并把速度设置发送给正确的页面；代码不把这些 URL 上传。

## 网站权限

`http://*/*` 和 `https://*/*` 允许扩展在用户授权的网站上发现和调整媒体。`all_frames` 用于已获授权的嵌入播放器。Safari 实际授予的权限仍由用户决定。

网页桥接传递速度、锁速、音调和播放器状态，不传递已保存的网站列表。网页自身可观察其媒体元素速度；不要将这套控制当成隔离恶意网页的安全边界。

## 清除与控制

- 关闭「记住此网站」会删除当前主机名对应的偏好。
- 关闭标签页会删除其会话记录。
- 可在 Safari 设置中撤销网站访问权限或停用扩展。
- 完全移除扩展及其存储可通过 Safari / macOS 的应用管理操作完成，具体清理行为取决于系统版本。

## 仓库页面与扩展的区别

GitHub 托管仓库、下载和问题反馈；README 徽章还会请求 GitHub 或 Shields.io。访问这些页面适用相应平台的政策。这些请求不由已安装扩展在运行时发出。

隐私相关问题可以通过仓库 Issues 提交，请避免包含私人网页内容、访问令牌和个人资料。安全问题按 [SECURITY.md](../SECURITY.md) 私下报告。
